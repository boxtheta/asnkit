Examples
========

This folder contains executable example scripts.

``x509_to_json``
   Dump an X.509 certificate, in PEM or DER, as JSON.

``any_defined_by``
   Compile TOML selector-to-type mappings, convert typed payloads between
   codecs, and generate models. Includes all four selector kinds, imported
   types and OIDs, a nested collection, and a known raw OpenType choice.

``compiled``
   Compiled specifications (``.asni``) and syntax trees (``.asnst``),
   and how to make and load them.

``corpus``
   Compiled files of every combination of signed, encrypted and
   bound, for testing a reader.

``compact_extensions_uper``
   More compact UPER encoding without extension markers.

``programming_types``
   Types often found in programming languages.

``playground``
   A web page that compiles ASN.1 and encodes a value with every codec,
   with the compiler and the runtime as WebAssembly.
